How to Use FHE on This Website

1️⃣ Generate Key Pair Start by generating a key pair. Download and securely store both keys on your device.

2️⃣ Encrypt a File using your Public Key Upload the file you want to protect and select your public key. The system will encrypt the file and allow you to download the encrypted version.

3️⃣ Decrypt a File using your Secret Key Upload the encrypted file together with your secret key. The system will decrypt the file and provide the original file for download.
